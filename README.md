# Родзал

Платформа клинических модулей для родильного зала: одна запись на одни роды, общие данные пациентки,
**общая хронология** и **единый протокол в Word**, модули по клиническим рекомендациям и **помощник** на базе знаний.

**Разработчик:** Осокин Иван Павлович, врач акушер-гинеколог · [t.me/dr_osokin](https://t.me/dr_osokin)

> ⚠️ Учебный прототип и средство поддержки решений. Не медицинское изделие, не заменяет клиническое суждение
> врача, клинические рекомендации и инструкции к препаратам.

| Второй период родов | переносится | авторский алгоритм |

## Ядро

- **Запись «Роды»** (`src/core/record.ts`): пациентка, ручные записи, данные модулей.
- **Модуль** подключается через `ModuleDef` (`src/core/modules.ts`): статус для главной, события для общей хронологии,
  раздел общего протокола Word, контекст для помощника. Реестр — `src/modules/registry.ts`.
- **Общие сервисы**: голосовые таймеры, окна подтверждения (работают и на claude.ai), сохранение файлов, Word-кит.
- **Перенос данных**: при первом запуске на устройстве забираются записи КТГ-навигатора и ПК-чек-листа
  (на GitHub Pages все приложения одного автора делят хранилище браузера). Импорт JSON из обоих приложений.

## Помощник

Работает в версии для claude.ai (`npm run build:claude`): отвечает через аккаунт Claude того, кто открыл страницу.
Видит базу знаний и данные текущих родов **без ФИО и номера истории**.

- База КТГ: `src/core/assistant/knowledge/ktg.md`.
- База ПК собирается автоматически из чек-листа и справочника доз модуля.
- Конспект книги Chandraharan: `src/core/assistant/knowledge/chandraharan.md` (вставляется автором).
- Правила ответа: `src/core/assistant/prompt.ts` (ссылки на источники, дозы только из базы, сначала действия).

В офлайн-версии помощник отключён — данные не покидают устройство.

## Запуск

```bash
npm install
npm run dev           # разработка
npm test              # тесты: ядро, КТГ, ПК, протокол Word
npm run build         # офлайн-PWA в dist/ (GitHub Pages)
npm run build:single  # один файл dist-single/index.html
npm run build:claude  # один файл dist-claude/index.html для публикации на claude.ai (помощник)
```
