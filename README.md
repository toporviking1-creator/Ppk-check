# КТГ-навигатор

Веб-приложение по **физиологической интерпретации КТГ** (Chandraharan) с параллельной классификацией
**FIGO 2015 / КР РФ «Признаки внутриутробной гипоксии плода…» (2023)**: оценка у постели, голосовой таймер
3-6-9-12-15, тренажёр на синтетических лентах, справочник и протокол в Word.

**Разработчик:** Осокин Иван Павлович, врач акушер-гинеколог · [t.me/dr_osokin](https://t.me/dr_osokin)

> ⚠️ Учебный прототип и средство поддержки решений. Не медицинское изделие, не заменяет клиническое суждение
> врача, клинические рекомендации и инструкции к препаратам.

## Разделы

- **Оценка** — разметка ленты кнопками (базальный ритм и его исходное значение, вариабельность, ZigZag,
  синусоидальный ритм, цикличность, децелерации и их характер, пролонгированная децелерация, схватки) и
  клинический контекст (окситоцин, потуги, эпидуральная, гипотония, лихорадка, меконий, кровотечение,
  выпадение пуповины, рубец, ЗРП, перенашивание, лекарства). Заключение в реальном времени:
  - тип гипоксии — острая / подострая / постепенно развивающаяся / хроническая / негипоксическая причина;
  - стадия ответа плода — компенсация → катехоламины → декомпенсация → претерминальное («лестница»);
  - рост базального ритма от исходного (порог 10 %), ориентир скорости снижения pH;
  - категория физиологически и по FIGO/КР с причинами;
  - что делать «сейчас» и чего не делать; время переоценки; отметка выполненных действий;
  - запись в историю одной кнопкой (копирование), сохранение в карту пациентки.
- **Таймеры** — пролонгированная децелерация 3-6-9-12-15 с голосом, вибрацией и удержанием экрана,
  старт «задним числом», быстрые отметки действий и хронология; напоминание о переоценке; счётчик схваток
  (тахисистолия).
- **Тренажёр**
  - *Разбор лент* — 15 случаев трёх уровней (норма, сон плода, ранние, компенсированный стресс, тахисистолия,
    катехоламиновая стадия, подострая, острая после эпидуральной, отслойка, хроническая, хориоамнионит,
    синусоидальный, ZigZag, декомпенсация, «лестница»): разметка, тип гипоксии, стадия, FIGO, тактика →
    баллы и разбор физиологии.
  - *Живая лента* — 7 сценариев в реальном времени (×1/×4/×10): гиперстимуляция, гипотония после
    эпидуральной, аортокавальная компрессия, выпадение пуповины, отслойка, подострая гипоксия во II периоде,
    разрыв матки. Действия меняют ход событий; разбор по вехам 3-6-9-12-15 и модельный pH при рождении.
- **Справка** — принципы, типы гипоксии, атлас паттернов, 3-6-9-12-15, негипоксические причины,
  внутриматочная реанимация, таблица FIGO/КР, ловушки, источники.
- **Пациентки** — серия оценок, график базального ритма относительно исходного (+10 %), хронология,
  **протокол в Word (.docx)**, резервная копия JSON.

Работает офлайн (PWA), данные только на устройстве, светлая/тёмная тема, телефон и планшет.

## Запуск

```bash
npm install
npm run dev          # разработка
npm test             # тесты: интерпретатор ↔ ключи тренажёра, FIGO, синтезатор, живая лента, Word
npm run build        # сборка в dist/
npm run build:single # всё приложение одним файлом dist-single/index.html
```

GitHub Actions публикует сборку на GitHub Pages при пуше в основную ветку
(Settings → Pages → Source: GitHub Actions).

## Структура

- `src/ktg/` — знания и чистая логика: `interpret.ts` (физиологическая интерпретация + FIGO),
  `synth.ts` (синтезатор КТГ), `actions.ts`, `record.ts` (запись в историю), `labels.ts`.
- `src/training/` — случаи тренажёра (`cases.ts`) и симулятор живой ленты (`live.ts`).
- `src/state/` — хранилище и глобальные таймеры. `src/export/` — Word. `src/components/` — интерфейс.

Тест `ktg.test.ts` проверяет, что интерпретатор приходит к тем же выводам, что и ключи всех случаев
тренажёра, а синтезированные ленты имеют заявленный базальный ритм.
