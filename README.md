# ПК-чек-лист — послеродовое кровотечение

Веб-приложение для работы **у постели пациентки**: пошаговый чек-лист по клиническим рекомендациям
«Послеродовое кровотечение» (РОАГ, ААР, АААР, МКП, **2025**; МКБ-10 O67.0/O67.8/O67.9, O72.0–O72.3)
с таймером, подсказками, расчётом доз и **выгрузкой отчёта в Word (.docx)**.

## Возможности

- **Экран «Сейчас»** — всё главное на одном экране: кнопки кровопотери, АД/ЧСС, и **3 следующих
  действия по алгоритму** (Б2, Б4, Б5) с учётом ситуации (массивная кровопотеря, выворот матки,
  остановка). Выполнили — нажали «✓», появляется следующее. Препараты вводятся одной кнопкой с дозой на массу.
- **Режим тренировки** — 4 сценария (гипотония матки, разрыв шейки, массивное кровотечение при КС
  с врастанием плаценты, выворот матки). Кровопотеря нарастает сама, монитор и лаборатория присылают
  вводные (анализы — через 10 мин после взятия), осмотры дают находки, лечение меняет ход событий.
  Скорость ×1/×2/×5, пауза. В конце — **разбор**: время ключевых действий, сроки КР 10/20/40 мин,
  ошибки, пропущенные пункты, оценка 0–100; разбор попадает и в отчёт Word (с пометкой «учебный»).
- **Чек-лист** (≈ 80 пунктов, 12 разделов): профилактика, оповещение, первая линия, 4Т и местный гемостаз,
  утеротоники и гемостатики, инфузия, массивная кровопотеря, хирургический гемостаз, анестезия,
  после остановки; отдельные разделы «Выворот матки» (Б6) и «Позднее ПК». Каждый пункт — с ответственным
  (Б2), ссылкой на раздел КР и УУР/УДД, отметкой времени, примечанием, статусом «не применимо».
  Пункты автоматически подстраиваются под способ родоразрешения (роды / КС). Фильтр по роли.
- **Таймер от начала кровотечения** и обратные отсчёты: решение о хирургии ≤ 20 мин, эритроциты ≤ 40 мин,
  действия анестезиолога ≤ 10 мин от диагностики массивной кровопотери, коагулограмма каждые 30 мин,
  контроль через 6 ч и НМГ через 12 ч после СЗП/ПКК/эптакога.
- **Кровопотеря**: быстрые кнопки +50…+500 мл, гравиметрия/визуально/cell saver, % ОЦК, степень по Б1,
  автоматическая диагностика массивной кровопотери (≥ 1500 мл / ≥ 25% ОЦК / ШИ ≥ 1).
- **Витальные функции**: шоковый индекс, САДср, диурез, критерии адекватности ИТТ.
- **Анализы**: проверка целевых показателей (Hb, тромбоциты, фибриноген, ПТВ/АЧТВ, Ли-Уайт, Ca²⁺, лактат, pH),
  интерпретация **РОТЭМ/ТЭГ** по Приложению А3.3, калькулятор криопреципитата по формуле КР.
- **Препараты**: дозы на массу тела (транексамовая кислота, СЗП, криопреципитат, тромбоциты, ПКК,
  эптаког альфа, кетамин и др.), журнал введений, контроль максимальных доз (окситоцин 60 МЕ,
  ТК 4000 мг, желатин 1000 мл), баланс ИТТ : кровопотеря.
- **Критерии качества** (9 критериев КР) — рассчитываются автоматически, с ручной корректировкой.
- **Выгрузка в Word**: полный отчёт (пациентка, сводка, бригада, чек-лист с временем, кровопотеря,
  витальные, анализы, ТЭГ/РОТЭМ, препараты, критерии качества, хронология, подписи) и **пустой бланк**
  для печати. Также резервная копия/импорт JSON.
- Справочник: Б1, Б2, этапы Б4/Б5, 4Т, А3.3, баллонная тампонада (Б7), реинфузия (Б8), анестезия, МКБ-10.
- Работает **офлайн** (PWA), данные хранятся **только на устройстве** (localStorage), тёмная тема,
  адаптация под телефон и планшет.

## Запуск

```bash
npm install
npm run dev          # разработка
npm test             # тесты (расчёты, правила, выгрузка .docx)
npm run build        # сборка в dist/ (для размещения на любом статическом хостинге)
npm run build:single # всё приложение в одном файле dist-single/index.html
```

Файл `dist-single/index.html` можно просто скопировать на планшет/компьютер и открыть в браузере —
сервер не нужен. Workflow GitHub Actions публикует сборку на GitHub Pages при пуше в основную ветку репозитория
(включите Pages → Source: GitHub Actions в настройках репозитория).

## Структура

- `src/protocol/` — знания протокола и чистая логика: `data.ts` (чек-лист, риски, 4Т), `drugs.ts` (дозы),
  `calc.ts` (ОЦК, ШИ, степень, интерпретация анализов/РОТЭМ), `alerts.ts` (подсказки и таймеры),
  `quality.ts` (критерии качества).
- `src/state/` — действия над случаем и хранилище.
- `src/protocol/steps.ts` — порядок «что делать сейчас».
- `src/training/` — сценарии, модель кровотечения, разбор.
- `src/export/docx.ts` — формирование документа Word.
- `src/components/` — интерфейс.

> Приложение — средство поддержки решений и документирования. Оно не заменяет клиническое решение врача
> и инструкции к лекарственным препаратам. «#» — применение вне инструкции (off-label).
